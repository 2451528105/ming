# 生成当前目录结构

## 用途

在用户需要查看“当前目录的文件/文件夹结构”时，快速输出可读的目录树。

## 默认行为

- 默认扫描深度：3 层。
- 默认输出格式：Markdown 代码块。
- 默认排除常见大目录与噪音目录：`.git`、`node_modules`、`bin`、`obj`、`dist`、`build`、`.idea`、`.vscode`。

## 执行步骤

1. 先确认目标目录：
   - 若用户明确给出目录，则使用该目录。
   - 否则使用当前工作目录。
2. 生成目录树：
   - 优先使用系统可用命令（如 `tree` 或等效方案）。
   - 如果命令不可用，使用可替代方式遍历目录并格式化为树形文本。
3. 处理输出：
   - 保留层级缩进与树枝符号，避免破坏可读性。
   - 当结果过大时，先给出前若干层并说明可继续展开。
4. 返回结果：
   - 使用 Markdown 代码块包裹目录树。
   - 如用户要求“完整”或“不排除”，再切换为全量输出。

## 可覆盖参数（按用户要求调整）

- 深度：例如 1/2/3/4/不限。
- 排除项：可增删目录名或文件模式。
- 输出格式：纯文本、Markdown 代码块、两者皆可。

## 输出模板

````markdown
当前目录结构（深度: <N>）：

```text
<directory-tree>
```
````

## 质量要求

- 不编造不存在的文件或目录。
- 若读取失败，说明失败原因并提供可行替代（如降低深度或缩小路径范围）。
- 结果尽量简洁，优先保证结构清晰。
